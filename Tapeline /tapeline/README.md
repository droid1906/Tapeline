# Tapeline

A transportation design studio in your pocket: reference library and moodboards, project tracker, sketch practice with a timer, a side-view proportions tool, events, community and resources. Works offline and installs on the iPhone home screen.

## Publish on GitHub Pages
1. Create a new public repository called `tapeline`.
2. Upload every file in this folder (Add file → Upload files), then Commit changes.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. After 1–2 minutes open `https://YOUR-NAME.github.io/tapeline/` in Safari.
5. Share → Add to Home Screen.

## Updating
Upload the new files to the same repository. The app shows "A new version is ready" the next time you open it.

## Your data
Everything stays on your iPhone (IndexedDB). Use Settings → Save backup regularly. Restoring a backup replaces what's in the app.
